Frequently asked questions

            

              A few practical details about the packages, previews, and images.
            

          

        

        

          

            Which systems are supported?
            

              Supported targets include CentOS Stream, Rocky, Alma, and Oracle
              Linux 10 RPMs plus Debian 12 and Ubuntu 24.04 amd64 DEBs.
            

          

          

            
              What is the difference between stable and rolling?
            
            

              Stable tracks validated GlusterFS releases. Rolling contains
              preview builds from upstream development and should be treated as
              testing software.
            

          

          

            
              Should I use a package repository or the container image?
            
            

              Use the native RPM or APT repository when integrating with a host
              operating system. Use the digest-pinned GHCR image when you want a
              reproducible GlusterFS runtime.
            

          

          

            Are packages and repository metadata signed?
            

              Yes. RPMs, DEBs, and repository metadata are signed before
              publication. The public signing key and verification links are
              available in the verification panel below.
