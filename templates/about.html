About this project

Eliware GlusterFS provides signed, tested GlusterFS packages and reproducible container images for RPM and Debian-family systems.

What we publish

  • EL10 x86_64 RPMs and Debian-family amd64 DEBs for stable releases.
  • Rolling preview packages for testing upstream development.
  • Digest-addressable container images hosted on GHCR.
  • Build metadata, signatures, checksums, and provenance records.

Source and support

Build automation and packaging changes are available in the packaging repository. The upstream project is GlusterFS.
